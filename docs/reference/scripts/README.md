# Script reference

These pages document the generated deployment script interfaces.

- [`container_install.sh`](container-install.md) — host-side deployment orchestration, permissions, builds, bootstrap, and acceptance.
- [`install.sh`](install.md) — profile-owned staging and bootstrap operations; currently generated by Django.
- [`container_start.sh`](container-start.md) — repeatable application runtime startup.
- [`smoke_test.sh`](smoke-test.md) — final generated deployment acceptance checks.

```text
container_install.sh -> host-side deployment orchestration
install.sh           -> profile stage/bootstrap operations
container_start.sh   -> repeatable runtime startup
smoke_test.sh        -> final generated acceptance checks
```
