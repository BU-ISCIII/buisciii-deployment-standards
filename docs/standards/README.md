# Standards

Standards are normative: they define what a compliant BU-ISCIII deployment must satisfy. Guides describe procedures for meeting these requirements.

- [Application installation contract](application-installation-contract.md) — common generated artifacts, lifecycle, ownership, and acceptance requirements.
- [Infrastructure requirements](infrastructure-requirements.md) — host, engine, network, storage, access, monitoring, and recovery requirements.
- [Security requirements](security-requirements.md) — configuration, image, exposure, permission, and deployment security controls.
- [Exceptions and compliance](exceptions-and-compliance.md) — assessment evidence and documented exceptions.

Use the [installation checklist](../templates/installation-checklist.md) to collect review evidence.
