# Creating a project

How to create a deployment baseline for an application with this repository's
scaffold.

> **Status:** Documentation outline. Detailed guidance will be added incrementally.

## Future sections

- Create or clone the application repository
- Obtain this standards repository
- Create `project.json` from the [example](../scaffold/project.json.example)
- Select services, profiles, and addons
- Run `scripts/scaffold.py init`
- Review generated files
- Commit the baseline
- Choose the next configuration and deployment steps
