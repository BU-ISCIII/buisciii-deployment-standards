# Deployment standards

This directory contains normative requirements: statements about what must be
true for a deployment to comply with the BU-ISCIII deployment standard.

Normative documents use **MUST** for requirements, **SHOULD** for recommendations
that need a documented reason to omit, and **MAY** for optional behavior. Guides
describe procedures, while reference pages describe the exact behavior or shape
of an implementation artifact.
