# Infrastructure requirements

Defines the infrastructure conditions that every compliant deployment must meet.
It belongs here when it is an environment-level requirement independent of a
specific framework. Request procedures and provider-specific instructions belong
in [guides](../guides/README.md), not here.

> **Status:** Documentation outline. Detailed requirements will be added incrementally.
