# Security requirements

Defines cross-cutting security requirements for compliant deployments. It belongs
here when the control applies generally; framework-specific controls belong in a
[profile](../profiles/README.md), and implementation steps belong in guides.

> **Status:** Documentation outline. Detailed requirements will be added incrementally.
